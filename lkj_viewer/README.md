# 兰州局工务类 LKJ 基硎数据管理工具

基于 Python + tkinter 的桌面 GUI 工具，用于可视化浏览和编辑 LKJ 基硎数据 Excel 文件。

## 功能特性

- **分类罗列**: 13 个工作簿按"线路信息/车站信息/速度信息/线路特征"四大类分组显示
- **快速查询**: 全列实时搜索 + 按指定列筛选
- **可视化编辑**: 双击单元格直接编辑，回车确认
- **增删行**: 添加空行、删除选中行、复制行
- **排序**: 点击表头列排序
- **保存**: 修改写回原 Excel 文件，支持另存为
- **导出 CSV**: 单个工作簿导出为 CSV

## 快速启动

```bash
cd lkj_viewer
python main.py
```

程序启动后自动加载同目录下的 Excel 文件。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存 |
| Ctrl+N | 添加行 |
| Ctrl+D | 删除行 |
| 双击单元格 | 编辑 |
| Esc | 取消编辑 |

## 打包为 EXE

```bash
pip install pyinstaller
python build.py
```

生成的可执行文件位于 `dist/LKJ数据管理工具/` 目录下。

## 文件结构

```
lkj_viewer/
├── main.py            # 主程序 (GUI)
├── excel_handler.py   # Excel 读写模块
```
